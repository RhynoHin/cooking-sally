# Cooking Sally

原創繁體中文煮食遊戲，針對 iPhone 直向、右手拇指操作設計。

## 遊玩

GitHub Pages: https://rhynohin.github.io/cooking-sally/

8 道食譜、37 個步驟，包含切菜、刨皮、攪拌、倒材料、控制火候、塑形與擺盤。
完成料理可以獲得獎牌、解鎖食譜，並陪 Sally 完成開店故事。

- 手機：在右下角操作區劃動、畫圈或按住。按鈕靠近底部。
- 電腦：直接在工作枱操作。
- 平均 60 分解鎖下一道；75 分銀牌、90 分金牌。
- 自由練習不限時，可試全部食譜。
- 最佳分數儲存在目前瀏覽器；清除網站資料會刪除紀錄。
- 點擊音樂或試聲按鈕啟用音訊。

## 本機執行

```sh
python3 -m http.server 8765
```

開啟 http://localhost:8765 。無需 API 金鑰或建置工具。

## 美術與聲音

角色與食物為原創生成插畫；廚房與工具由 Canvas 繪製。背景音樂與音效為原創合成音訊。食物素材說明見 FOOD-ART.md。

## 測試

已測試全部八道食譜與結局，並在食物美術更新後驗證七種操作、分數、解鎖、保存、暫停及逾時。手機版面以 Chromium / WebKit 模擬檢查；實體裝置手感、Safari 音訊路由仍可能有所不同。

本遊戲為原創網頁作品，並非官方 Cooking Mama 遊戲。
